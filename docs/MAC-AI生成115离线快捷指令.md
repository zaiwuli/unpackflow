# 交给 Mac AI 的 115 离线快捷指令生成规范

把下面“任务说明”整段复制给 Mac 上能够操作“快捷指令”App 的 AI。先把接口地址中的示例域名换成设置页显示的真实地址。

## 任务说明

请在 macOS 的“快捷指令”App 中创建一个名为“115 离线导入”的快捷指令。不要生成 `.shortcut` 源文件，不要使用命令行拼装 plist；请直接在“快捷指令”App 中逐项创建操作，完成后让我检查并手动运行测试。

接口地址：

```text
https://你的服务器地址/api/115/offline/import
```

后端不需要 Authorization、Bearer Token、Cookie 或其他请求头。

快捷指令要求：

1. 允许从共享表单接收“文本”“URL”和“文件”，支持在 iPhone、iPad 和 Mac 的共享菜单运行。
2. 如果存在共享输入：
   - 输入是文件时，读取文件中的文本。
   - 输入是文本或 URL 时，转换成文本。
3. 如果没有共享输入，使用“询问输入”，提示文字为“粘贴 ED2K、Magnet 或下载链接，支持一行一条”，输入类型为多行文本。
4. 将最终文本保存为变量“离线链接”。
5. 使用“获取 URL 内容”请求上述接口：
   - 方法：POST
   - 请求正文：JSON
   - 字段 `text`：变量“离线链接”
   - 字段 `auto_extract`：布尔值 `true`
   - 不添加任何请求头
6. 请求成功后只显示 JSON 的 `message` 字段，例如“本次导入 3 条”；不要将返回的原始 JSON 或批次详情显示给用户。
7. 请求失败时显示错误信息，不要静默结束。
8. 快捷指令图标可使用蓝色下载图标。

请创建完成后逐项报告实际添加的操作名称和顺序，不要声称已完成未实际执行的步骤。

若分享的是本地 TXT 文件，请先在快捷指令中读取文件文本，再将文本传给后端。远程 TXT 下载链接不会由后端自动下载和解析；可以在快捷指令中先下载并读取文本。

## 最简单的人工版本

如果 AI 无法操作快捷指令 App，可手动创建以下 4 个操作：

1. “询问输入”：类型选择文本，允许多行。
2. “URL”：填写设置页给出的离线导入接口地址。
3. “获取 URL 内容”：POST，正文选择 JSON，添加 `text`＝询问输入结果、`auto_extract`＝布尔值 true；不添加请求头。
4. “显示结果”：显示“获取 URL 内容”的返回值。

首次测试建议只提交一条 Magnet 或 ED2K 链接。服务器必须能从 Mac 或 iPhone 所在网络访问；公网部署建议使用 HTTPS。
