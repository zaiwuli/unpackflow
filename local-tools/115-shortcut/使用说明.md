# 115 离线导入快捷指令

1. 把整个 `115-shortcut` 文件夹复制到 Mac。
2. 打开“终端”，执行：

   ```bash
   chmod +x 生成115离线快捷指令.command
   ./生成115离线快捷指令.command
   ```

3. 输入配置页显示的离线导入接口地址，以及“快捷指令导入令牌”。
4. macOS 会调用 Apple 的 `shortcuts sign` 完成签名，并自动打开生成的 `115离线导入.shortcut`。
5. 点击“添加快捷指令”。运行后粘贴一条或多条 ED2K、Magnet 或普通下载链接即可。

建议使用 HTTPS 公网地址。若使用局域网 HTTP 地址，iPhone 可能因网络权限或安全策略无法访问。

这个目录是本地工具，不需要提交到 Git。生成后的快捷指令内含访问令牌，请勿把文件公开分享。
